# NovaBank Retention Targeting

Predictive targeting framework and 90-day pilot recommendation for a retention campaign, built for the Quantic MSBA Analytics Methods and Frameworks project.

## Files
- `NovaBank_Analytics_Project.ipynb`: full analysis, from data preparation to decision framework
- `requirements.txt`: library versions used

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Download the dataset from the UCI link below, unzip it, and place `bank-additional-full.csv` in the same folder as the notebook.
3. Open the notebook in Jupyter and run **Kernel → Restart & Run All**.

## Data
Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI Machine Learning Repository.
https://archive.ics.uci.edu/dataset/222/bank+marketing
